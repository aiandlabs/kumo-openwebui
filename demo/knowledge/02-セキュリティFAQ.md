# セキュリティ・データ取り扱い FAQ（デモ用・架空）

最終更新: 2026年9月15日 / 情報セキュリティ室

> この資料は Kumo のデモ用に作られた架空の資料です。

## Q1. データはどこで処理・保管されますか？
推論、ログ、ファイル保管のすべてを日本国内のデータセンターで行います。海外のリージョンやサービスには送りません。埋め込み（ベクトル化）と再ランキングも国内で処理します。

## Q2. 入力したデータはモデルの学習に使われますか？
使いません。契約上も明記しています（利用規約 第12条）。

## Q3. ログの保管期間は？
API のリクエストログは 30日 保管した後に削除します。エンタープライズプランでは 0日（保存しない）を選べます。

## Q4. セキュリティチェックシートには対応していますか？
対応しています。情報セキュリティ室が受け付けから **5営業日以内** に回答します。依頼は営業担当から社内ポータルの「チェックシート依頼」で出してください。お客様の独自様式も受け付けます。

## Q5. 認証・認可は？
ビジネスプラン以上で SAML / OIDC の SSO に対応します。IP アドレス制限はすべてのプランで利用できます。

## Q6. 第三者認証は？
ISMS（ISO/IEC 27001）を取得しています。SOC 2 Type II は 2027年 取得予定です。
