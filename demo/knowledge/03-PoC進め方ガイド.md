# PoC 進め方ガイド（デモ用・架空）

最終更新: 2026年8月20日 / 営業企画部

> この資料は Kumo のデモ用に作られた架空の資料です。

## 1. 期間
PoC の標準期間は **2週間**。無償で実施できるのは最長 **4週間** までです。4週間を超える場合は営業部長の承認が必要です。

## 2. 開始前に合意すること
1. 評価基準（例: 回答の正確性、応答速度、現場の満足度）と合格ライン
2. 評価に使うデータと、データの持ち出し可否
3. 決裁者と、PoC 後の稟議の時期

## 3. 進行中
* 週1回、先方の担当者と30分の定例を持つ。
* 定例の議事録は Kumo の活動履歴に登録する。

## 4. 止まっている PoC の再設計
活動履歴の最終更新から **30日以上** 経った PoC は「停滞」とみなします。担当者は次の順で対応してください。

1. 先方の決裁者（担当者ではなく）に、評価基準と合格ラインをもう一度確認する。
2. 評価範囲を1つの業務に絞り、2週間で結果が出る形に作り直す。
3. 1週間以内に返答がない場合は、営業課長が同行して訪問する。

値引きの提示は、再設計の合意が取れてから行います（「価格表とディスカウント規程」第2章）。
